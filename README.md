# Loan Application Form

Это приложение представляет собой форму заявки на займ, разработанную с использованием React, TypeScript и Vite. Оно
включает многошаговый wizard для ввода персональных данных, адреса и параметров займа, с интеграцией Redux для
управления состоянием и валидацией форм.

## Описание

Проект демонстрирует создание современного веб-приложения с использованием:

- **React** для UI-компонентов.
- **TypeScript** для типизации.
- **Vite** как инструмента сборки и разработки.
- **Redux Toolkit** для управления состоянием.
- **React Hook Form** для обработки форм.
- **Bootstrap** для стилизации.

Приложение состоит из трех шагов:

1. Ввод персональных данных.
2. Ввод адреса.
3. Выбор параметров займа (сумма и срок).

После заполнения формы данные отправляются на сервер (в демонстрационных целях используется thunk для симуляции).

## Требования

- Node.js версии 18 или выше.
- npm как менеджер пакетов.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd test-project
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## Запуск проекта

1. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

2. Откройте браузер и перейдите по адресу `http://localhost:5173` (или порту, указанному в консоли).
